# 🛒 Online Grocery Store

A simple and responsive web-based Online Grocery Store application built using **HTML, CSS, and JavaScript**. This project allows users to browse various grocery products, search items dynamically, add them to a shopping cart, and calculate the final bill including delivery charges based on order value.

---

## ✨ Features

- **Product Catalog:** Browse through a variety of fresh groceries (fruits, vegetables, dairy, snacks, and staples).
- **Live Search:** Instantly filter products by typing their names into the search bar.
- **Shopping Cart:** Add items to your cart with real-time total calculations.
- **Smart Delivery Charge:** 
  - **FREE delivery** on orders above ₹500.
  - Standard **₹40 delivery fee** for orders ₹500 and below.
- **Checkout & Validation:** Customer name and 10-digit phone number validation before order generation with a detailed receipt summary.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3
- **Scripting:** Vanilla JavaScript (ES6)
- **Styling:** Flexbox, CSS Grid & Custom UI Design
